# Musein deck

Eight selected slides, with component entrances and embedded video.

Open `index.html` on any static web host. Use arrow keys, Space, the bottom controls, or swipe to navigate. Video playback is muted by default; use its controls for audio.

## GitHub Pages

In repository Settings → Pages, select “Deploy from a branch”, then `main` and `/ (root)`. Save.

The published URL will be `https://seasea-cc.github.io/musein-deck/` once GitHub Pages is enabled.
